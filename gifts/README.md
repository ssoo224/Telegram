# مجلد الهدايا (gifts/)

كل شي يخص الهدايا هنا، وما نلمس index.html إلا بالحد الأدنى.

| الملف | شنو بيه |
|---|---|
| `gifts.css` | ستايل الهدايا (البطاقات، المتجر، المحفظة، كارت النجوم) |
| `gifts.js` | منطق Plush Pepe: الرصيد، الترقية العشوائية، المتجر، صفحة الهدية، سجل النجوم |
| `models.js` | قائمة نماذج Plush Pepe الـ50 (الاسم + الندرة + اسم الملف) |
| `cat-models.js` | قائمة نماذج Scared Cat الـ50 (الاسم + الندرة + اسم الملف) |
| `cat-models/` | ملفات أنيميشن Scared Cat |
| `models/` | ملفات الأنيميشن `.tgs` للنماذج، كل واحد يتحمّل لحاله وقت الحاجة |
| `star-gift.js` | إهداء النجوم من المطور + كارت الهدية البابلي بالمحادثة |

ترتيب التحميل بـ index.html (قبل `</body>` تقريباً، بعد السكربت الرئيسي):
`models.js` ← `cat-models.js` ← `gifts.js` ← `star-gift.js`

## شلون نضيف هدية جديدة (مثلاً Baby Plush)
1. أنيميشنها (ملف .tgs) نحطه داخل `gifts/models/` (وما نحتاج base64).
2. نسوي ملف `gifts/baby.js` فيه الموديلات والأسعار والعرض.
3. نضيف `<script src="gifts/baby.js">` بـ index.html.

## شلون نضيف موديل جديد لـ Plush Pepe
نحط ملف `.tgs` بمجلد `models/` ونضيف سطر بآخر قائمة `models.js`. لا تغيّر ترتيب الموجود حتى ما تخرب الهدايا المرقّاة.
4. ما نحتاج نغير index.html بأي مكان ثاني.

## ملاحظة
قواعد Firestore (`firestore.rules`) ما احتاجت أي تعديل.
بعد الرفع على جيت هاب، إذا بقت النسخة القديمة بالمتصفح، غيّر رقم `?v=1` بروابط الملفات.

## أنواع الهدايا
كل نوع معرّف بـ `GIFT_KINDS` أول `gifts.js` (الاسم، مجموعة فايربيس، المبيعات، العدد 30، السعر، مجلد النماذج).
- Plush Pepe: `pepes` + `pepeSales`
- Scared Cat: `cats` + `catSales`
نوع جديد = ملف نماذج + مجلد أنيميشن + سطر بـ `GIFT_KINDS` + نسخ قواعد `cats`/`catSales`/`lastBuyCat` بـ firestore.rules باسم جديد.

## الصور المصغّرة (thumbs)
كل نموذج له صورة webp ثابتة 256px بمجلد `thumbs/` داخل مجلد نماذجه (`models/thumbs` و`cat-models/thumbs`، الاسم نفس اسم ملف الـ.tgs).
تُستعمل بمربعات الشبكة بالبروفايل بدل الأنيميشن. موديل جديد = أضف `.tgs` وصورته webp بنفس الاسم.
